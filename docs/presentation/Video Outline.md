Recording Tips
Screen Resolution: Record at 1920x1080 or 1280x720
Browser: Use Chrome with a clean profile (no extensions visible)
Data: Use a real project scan so the results look authentic
Pacing: Leave 0.5s pause between scenes for transitions
Avatar Placement: Bottom-right corner, ~20% of frame width
Music: Light, upbeat background track (lower during voiceover)
Suggested Tools
Avatar: HeyGen, Synthesia, or D-ID
Screen Recording: OBS, Loom, or ScreenFlow
Editing: Descript, CapCut, or Premiere
